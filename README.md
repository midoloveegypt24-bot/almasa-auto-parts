## 3. المعمارية التقنية للمنصة

- **الواجهة الأمامية (Frontend):** واجهة عربية أصيلة تدعم RTL بالكامل، مبنية بواسطة Tailwind CSS، أيقونات FontAwesome 6، وخطوط Google العربية (Cairo و Tajawal).
- **الواجهة التفاعلية وسلة المشتريات:** محرك JavaScript خفيف وسريع يعتمد على التخزين المحلي `localStorage`، بحث فوري سريع بالاسم والكود، نافذة سلة منزلقة (Cart Drawer)، ونموذج شراء فوري منبثق.
- **الخادم الخلفي (Backend):** Python Flask 3 مع بنية برمجية معيارية للـ REST APIs وتوثيق العمليات المحاسبية.
- **قواعد البيانات:**
  - **قاعدة البيانات النشطة:** SQLite 3 مع تفعيل المفاتيح الأجنبية `PRAGMA foreign_keys = ON` وفهارس البحث.
  - **مخططات الإنتاج المرفقة:**
    - `data/schema_postgres.sql` لنظام PostgreSQL.
    - `data/schema_mssql.sql` لنظام Microsoft SQL Server.
- **التكامل مع واتساب:** زر واتساب عائم بجميع الصفحات + زر طلب فوري في كل كارت صنف يقوم بتشفير وتجهيز رسالة واتساب كاملة بكود الصنف، اسمه، موديل السيارة، والسعر.
- **منظومة السداد الإلكتروني (Manual Verification Workflow):**
  - دعم المحافظ الإلكترونية وإنستاباي على الرقم `01212429139`.
  - رفع إيصال التحويل البنكي وتوثيق الرقم المرجعي.
  - تبقى حالة الطلب **"قيد المراجعة" (PENDING)** حتى يدخل المدير ويعتمد الدفع يدوياً.

## 4. تشغيل المشروع محلياً (Quick Start)

### المتطلبات:
- تثبيت Python 3.10+
- الحزم المذكورة في `requirements.txt`

### خطوات التشغيل:
```bash
# 1. الدخول إلى مجلد المشروع
cd C:\Users\windows10\.gemini\antigravity\scratch\almasa-auto-parts

# 2. تثبيت الحزم (إن لم تكن مثبتة مسبقاً)
pip install -r requirements.txt

# 3. تشغيل الخادم
python app.py
```

سيعمل الخادم فوراً على الرابط:  
👉 **http://127.0.0.1:5000**

## 7. دليل النشر على السيرفر الإنتاجي (Production Deployment)

للنشر على خادم Linux أو Windows Server في بيئة إنتاجية حقيقية:

1. **ضبط متغيرات البيئة (`.env`):**
   ```env
   SECRET_KEY=your-super-strong-production-random-key
   FLASK_ENV=production
   ```
2. **تشغيل الخادم عبر WSGI Production Server:**
   - في بيئة Linux:
     ```bash
     gunicorn -w 4 -b 0.0.0.0:5000 app:app
     ```
   - في بيئة Windows Server:
     ```bash
     waitress-serve --listen=127.0.0.1:5000 app:app
     ```
3. **إعداد Nginx كـ Reverse Proxy وتركيب شهادة SSL (Let's Encrypt).**
